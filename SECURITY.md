# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 5.x     | ✅ |
| 4.x     | Critical security fixes only (best effort) |
| < 4.0   | ❌ |

## Reporting a Vulnerability

Please **do not** open a public issue. Report privately through
[GitHub Security Advisories](https://github.com/Ahoo-Wang/CoCache/security/advisories/new).

Include the affected version, a description of the impact, and reproduction steps.
You will get an acknowledgement within 3 business days. Fixes are released as patch versions
and disclosed in a GitHub Security Advisory after the release.
